## Modelo de Licenciamento

O projeto **NiloScript** é disponibilizado como código aberto com restrições. Não é permitida a modificação direta do código-fonte original. Entretanto, é permitida a criação de _forks_ e de projetos derivados, desde que sejam respeitados os termos de uso estabelecidos para o projeto.

# Direitos e Restrições de Uso

- Uso permitido exclusivamente para fins acadêmicos e não comerciais.
- É permitida a distribuição de _forks_ do projeto.
- Não é permitida a modificação do repositório principal.
- Os projetos derivados (_forks_) não podem ser comercializados.

## Política de Distribuição

O projeto será disponibilizado publicamente por meio do **GitHub**. Não há previsão de distribuição comercial.

## Estratégia de Manutenção e Suporte

- Correções pontuais de defeitos identificados durante a evolução da linguagem.
- Atualizações ocasionais para garantir compatibilidade com novas versões de ferramentas externas, como **ANTLR** e **LLVM**.
- Suporte comunitário por meio de _issues_ e discussões disponibilizadas no repositório do projeto no GitHub.

## Fonte de Financiamento

O projeto não possui financiamento. Seu desenvolvimento e manutenção são realizados de forma independente, sem patrocínio, comercialização ou recebimento de doações.
