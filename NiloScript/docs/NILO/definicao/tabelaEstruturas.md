# Tabela de Estruturas da Linguagem

| Estrutura da Linguagem          | Descrição                                                                                                | Estrutura exemplo                                                                                                                           |
| ------------------------------- | -------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------- |
| **Variável**                    | Item que armazena um valor. Quando declarada pela primeira vez, deve ser acompanhada de seu tipo.        | `a :inteiro = 5;`                                                                                                                           |
| **Laço de iteração**            | Executa repetidamente um bloco de código enquanto a condição especificada for verdadeira.                | `enquanto (a > b) { ... }`                                                                                                                  |
| **Lista**                       | Estrutura utilizada para armazenar elementos de um mesmo tipo.                                           | `nome_variavel{2} :inteiro = [5, 80];`                                                                                                      |
| **Acesso à lista**              | Obtém o valor armazenado em uma posição específica da lista por meio de seu índice.                      | `nome_variavel[1];`                                                                                                                         |
| **Funcionalidade**              | Bloco de código reutilizável que pode receber parâmetros e retornar um valor.                            | `funcionalidade nome_funcao (parametro :tipo) :tipoRetorno {<br>&nbsp;&nbsp;&nbsp;&nbsp;...<br>&nbsp;&nbsp;&nbsp;&nbsp;retorne valor;<br>}` |
| **Invocação da funcionalidade** | Chamada de uma funcionalidade previamente declarada, informando os parâmetros necessários.               | `nome_funcao(parametro);`                                                                                                                   |
| **Mostrar**                     | Realiza a saída de dados no terminal, devendo utilizar a função correspondente ao tipo do valor exibido. | `mostrarInteiro(valor);`                                                                                                                    |
| **Pegar**                       | Realiza a entrada de dados pelo terminal, utilizando a função correspondente ao tipo esperado.           | `pegaInteiro;`                                                                                                                              |
| **Caso**                        | Executa blocos de código de forma condicional, podendo conter um bloco alternativo (`senao`).            | `caso (condicao) {<br>&nbsp;&nbsp;&nbsp;&nbsp;...<br>} senao {<br>&nbsp;&nbsp;&nbsp;&nbsp;...<br>}`                                         |
