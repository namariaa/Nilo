# Tabela de Palavras-Chave

| Palavra-chave         | Descrição                                                         | Exemplo de uso                                                                                                                            |
| --------------------- | ----------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------- |
| **pegaInteiro**       | Representa a entrada de números inteiros via terminal.            | `a :inteiro = pegaInteiro;`                                                                                                               |
| **pegaFlutuante**     | Representa a entrada de números de ponto flutuante via terminal.  | `a :flutuante = pegaFlutuante;`                                                                                                           |
| **pegaCaracteres**    | Representa a entrada de cadeias de caracteres via terminal.       | `a :caracter = pegaCaracteres;`                                                                                                           |
| **mostrarInteiro**    | Representa a saída de números inteiros via terminal.              | `mostrarInteiro(a);`                                                                                                                      |
| **mostrarFlutuante**  | Representa a saída de números de ponto flutuante via terminal.    | `mostrarFlutuante(a);`                                                                                                                    |
| **mostrarCaracteres** | Representa a saída de cadeias de caracteres via terminal.         | `mostrarCaracteres(a);`                                                                                                                   |
| **mostrarBool**       | Representa a saída de valores booleanos via terminal.             | `mostrarBool(a);`                                                                                                                         |
| **caso**              | Representa uma estrutura condicional.                             | `caso (condicao) {<br>&nbsp;&nbsp;&nbsp;&nbsp;...<br>}`                                                                                   |
| **senao**             | Representa o bloco executado quando a condição do `caso` é falsa. | `senao {<br>&nbsp;&nbsp;&nbsp;&nbsp;...<br>}`                                                                                             |
| **retorne**           | Indica o valor retornado por uma funcionalidade.                  | `retorne valor_retornado;`                                                                                                                |
| **verdadeiro**        | Representa o valor lógico verdadeiro.                             | `a :bool = verdadeiro;`                                                                                                                   |
| **falso**             | Representa o valor lógico falso.                                  | `a :bool = falso;`                                                                                                                        |
| **:)**                | Indica que a linha corresponde a um comentário.                   | `:) Esse é um comentário`                                                                                                                 |
| **enquanto**          | Representa uma estrutura de repetição.                            | `enquanto (a > b) {<br>&nbsp;&nbsp;&nbsp;&nbsp;...<br>}`                                                                                  |
| **funcionalidade**    | Representa a declaração de uma função da linguagem.               | `funcionalidade nomeFuncao(parametro :tipo) :tipoRetorno {<br>&nbsp;&nbsp;&nbsp;&nbsp;...<br>&nbsp;&nbsp;&nbsp;&nbsp;retorne valor;<br>}` |
