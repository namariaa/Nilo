# Tabela de Operadores

| Operador | Descrição                                                                                                                       |
| -------- | ------------------------------------------------------------------------------------------------------------------------------- |
| `;`      | Representa o fim de um comando.                                                                                                 |
| `*`      | Representa a operação matemática de multiplicação.                                                                              |
| `/`      | Representa a operação matemática de divisão.                                                                                    |
| `%`      | Representa a operação matemática de resto da divisão.                                                                           |
| `**`     | Representa a operação matemática de potenciação.                                                                                |
| `+`      | Representa a operação matemática de adição.                                                                                     |
| `-`      | Representa a operação matemática de subtração.                                                                                  |
| `>`      | Representa o operador de comparação **maior que**.                                                                              |
| `<`      | Representa o operador de comparação **menor que**.                                                                              |
| `>=`     | Representa o operador de comparação **maior ou igual a**.                                                                       |
| `<=`     | Representa o operador de comparação **menor ou igual a**.                                                                       |
| `!=`     | Representa o operador de comparação **diferente de**.                                                                           |
| `==`     | Representa o operador de comparação **igual a**.                                                                                |
| `{ }`    | Delimita blocos de código executados em estruturas condicionais, laços de repetição e funções.                                  |
| `( )`    | Utilizado para priorizar expressões matemáticas, delimitar condições em estruturas de controle e definir parâmetros de funções. |
| `[ ]`    | Utilizado para acessar elementos de uma lista por meio de seu índice.                                                           |
| `:)`     | Indica que a linha corresponde a um comentário.                                                                                 |
