# Tabela de Tipos

| Nome do Tipo  | Descrição                                                                                                                                   |
| ------------- | ------------------------------------------------------------------------------------------------------------------------------------------- |
| **Inteiro**   | Tipo primitivo utilizado para representar valores numéricos inteiros, ou seja, números sem parte fracionária.                               |
| **Flutuante** | Tipo numérico destinado à representação de valores reais, ou seja, números que possuem parte fracionária.                                   |
| **Caracter**  | Tipo destinado à representação de cadeias de caracteres, utilizado para representar textos.                                                 |
| **Bool**      | Tipo destinado à representação de valores booleanos, podendo assumir os valores verdadeiro ou falso.                                        |
| **Nada**      | Tipo destinado à representação da ausência de valor, utilizado especificamente como tipo de retorno de funções que não retornam resultados. |
