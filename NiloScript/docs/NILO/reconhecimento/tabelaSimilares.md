# Tabela de Similares

| Linguagem   | Descrição                                                                                                                                                                                                                   | Similaridades que minha linguagem deve ter                                                                               | Diferenciais que minha linguagem deve ter                                                                                                       |
| ----------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------- |
| **Potigol** | Linguagem funcional criada no IFRN, voltada para o ensino. Possui sintaxe simples e clara, sendo utilizada para introduzir conceitos de programação funcional sem complexidade excessiva.                                   | - Comandos em português.<br>- Compilador próprio que realize a tradução de forma independente.<br>- Tipagem obrigatória. | Sintaxe e estrutura próprias, voltadas à implementação de um compilador completo e à validação do modelo de processo NILO.                      |
| **Scratch** | Linguagem baseada em programação em blocos que permite a iniciantes aprender lógica de programação sem a necessidade de escrever código textual. É amplamente utilizada no ensino de algoritmos e pensamento computacional. | - Caráter didático.<br>- Comandos em português.                                                                          | Utilização de código textual em vez de blocos gráficos, aproximando o estudante da sintaxe utilizada em linguagens de programação tradicionais. |
