# Tabela de Ferramentas

| Ferramenta | Funcionalidade                                                                                                                                                                           |
| ---------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **ANTLR**  | Produção da gramática, seguida pela construção do lexer e do parser, resultando em uma árvore sintática concreta, adequada para servir como base para a geração de código intermediário. |
| **LLVM**   | Geração da representação intermediária e apoio à produção do código da linguagem.                                                                                                        |
