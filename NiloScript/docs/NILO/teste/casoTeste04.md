# Caso de teste 04: Operação de potenciação

O principal objetivo é validar a operação de potenciação e a avaliação de expressões matemáticas complexas.

### Pré-condições

- Compilador NiloScript configurado.
- Ambiente LLVM corretamente instalado.

### Código de teste

```niloscript
VARIABLE :inteiro = (6 * 1 - 7 / 1 + 3) ** 2;
mostrarInteiro(VARIABLE);
```

### Passo a Passo para a realização do teste

1. Compilar o programa.
2. Executar o programa.
3. Comparar a saída obtida.

### Resultado esperado

```text
4
```

### Critério de aprovação

O teste será considerado **Aprovado** caso as operações matemáticas e a potenciação sejam avaliadas corretamente.

### Resultado obtido

**Aprovado.**
